# GameGenie Agent

Agent: GameGenie

Description: AI assistant that helps kids generate and play games, manage the game library, and keep interactions safe and age-appropriate. It turns a child’s idea into a playable game after a short creative chat flow and encourages the child throughout the process.

Files:
- `agent-config.json` - main agent configuration
- `actions/action-group.json` - action definitions
- `prompts/system-prompt.md` - system prompt and response guidelines

Usage: This file provides human-readable context for maintainers and tooling. The portal uses a lightweight multi-turn idea flow: children can talk, build on ideas, and then press Create My Game when ready.
