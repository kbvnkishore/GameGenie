# Agents Overview

This repository contains two primary agents used by the GameGenie application:

- `game-genie` — Generates games from ideas and manages the game library.
- `kids-game-portal` — Portal-facing agent for featured games and submissions.

Each agent directory contains:

- `agent-config.json` — agent configuration
- `actions/` — action definitions (action-group.json)
- `prompts/` — system prompt files

If you add new agents, include a short `.agent.md` and `.instructions.md` in the agent folder.
