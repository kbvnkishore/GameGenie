# Coding Agent Context Files

This folder contains Copilot/coding assistant context files to help understand the GameGenie project structure.

Contents:
- `.agent.md` - Main coding agent metadata
- `.instructions.md` - Developer instructions for assistants
- `AGENTS.md` - Overview of game agents in the project
- `game-genie.md` - Context for the GameGenie game agent
- `kids-game-portal.md` - Context for the KidsGamePortal game agent

These files help automation tools, IDE assistants, and developers understand the codebase structure without modifying the actual code agents in `agents/`.
